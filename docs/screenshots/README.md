# Скриншоты приложения

PNG в этой папке получены из запущенного Windows-приложения Pulse: Flutter экспортирует отрисованные кадры через `RenderRepaintBoundary`. Это основной интерфейс и настоящий сервис чтения HID, без демонстрационных процентов и без подстановки тестовых данных. Системная рамка окна не включена в снимки.

Используется сохранённый пользователем выбор устройств. Генератор не меняет настройки. Если устройство спит или не отвечает, на снимке будет соответствующий статус.

Чтобы обновить снимки на Windows, сначала закройте Pulse через меню трея, затем выполните из корня проекта:

```powershell
.\tools\build.ps1 -Target tools/capture_screenshots.dart
Start-Process -FilePath '.\build\windows\x64\runner\Release\pulse_battery.exe' -WorkingDirectory (Get-Location).Path -Wait
.\tools\build.ps1
```

Специальная сборка снимет главное окно, выбор устройств и виджет в `docs/screenshots/`, после чего завершится. Последняя команда восстанавливает обычную сборку приложения. Запускайте `tools/package.ps1` только после восстановления обычной сборки.
